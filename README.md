SAFEZONE 🛡️

Cybersecurity Laboratory Simulation

SAFEZONE is a university cybersecurity project developed in a controlled and secure laboratory environment. The project focuses on simulating common attack scenarios and analyzing vulnerabilities in order to better understand cybersecurity threats and security measures.

🎯 Objectives

* Simulate cybersecurity attacks in a controlled environment
* Analyze vulnerabilities and security weaknesses
* Understand basic attack and defense techniques
* Identify security risks and propose appropriate security measures

🛠️ Technologies & Tools

* Python
* Kali Linux
* VirtualBox
* OpenSSH
* Metasploitable
* Linux

🔍 Project Activities

The project includes:

* Port scanning and service identification
* Vulnerability analysis
* SSH access in a controlled environment
* Hash and password security experiments
* Analysis of HTTP headers
* SSL/TLS analysis
* Security assessment of a simulated environment

⚠️ Disclaimer

This project is intended for educational purposes only and is conducted in an isolated and controlled laboratory environment. No unauthorized systems or networks are targeted.
